This thesis presents the design, implementation, and approbation of a modular, cloud‑native information system for managing customers, orders and deliveries within a manufacturing context, using Heidelberg Materials as a case. It addresses challenges in conventional, ERP‑centric workflows, including fragmentation, latency, reliance on manual intervention, and limited real‑time visibility. The proposed architecture leverages domain‑driven design with bounded contexts (Order, Delivery, User/Identity, Tracking), command and query responsibility segregation, and event sourcing patterns to create immutable order and delivery streams. Conceptual, logical, and communication models define microservice responsibilities, set API contracts, and guide event flows. These models support both web and mobile clients with real‑time updates, dynamic scheduling, notifications, and communication channels. The system integrates with existing enterprise resources through ERP synchronization, IoT sensor data ingestion, asynchronous messaging via a broker, and secure multi‑role access provided. The underlying technology stack ensures scalability, robust deployment automation, and system observability: ASP.NET Core, Azure services, RabbitMQ, Docker, Kubernetes, and GitHub Actions. An A/B test was conducted from March to April 2024 to evaluate the system’s usability and functional correctness. In this test, Group A (business clients) worked through order lifecycle scenarios, while Group B (suppliers) performed dispatch, routing, and delivery confirmations. The final evaluation focused on responsiveness, data integrity, security, automation, and business decision-making.
