
# Cloud and IT Terms Glossary

## Storage & Networking

| Term | Full Name | Description |
|------|-----------|-------------|
| OBS | Object Storage Service | An object-based cloud storage service that provides extensible, secure, reliable, and cost-effective data storage. |
| EIP | Elastic IP Address | Independent public IP addresses and bandwidth for the Internet. Can be flexibly associated with ECS, BMS, virtual IP, load balancer, or NAT gateway. Various billing modes available. |
| VPN | Virtual Private Network | Technology that encapsulates and transmits network data over another network, enabling secure access to resources that may be inaccessible from the public internet. |
| DNS | Domain Name Server | A TCP/IP network entity that maps domain names to IP addresses, enabling access to servers using memorable names while maintaining IP-based communication. |
| TCP/IP | Transmission Control Protocol/Internet Protocol | Suite of protocols for constructing worldwide internetworks. |
| WWW | World Wide Web | Large-scale hypermedia information system for browsing information. |
| S3 | Simple Storage Service | Amazon's scalable storage service for the Internet, designed for web-scale computing. |

## Virtualization & Compute

| Term | Full Name | Description |
|------|-----------|-------------|
| ARM | Advanced Reduced Instruction Set Computing Machines | CPU design strategy using simplified instruction sets for higher performance with fewer microprocessor cycles per instruction. |
| VMware | / | Leader in virtualization technology, providing software portfolio for virtualizing hardware resources to enable multiple virtual servers on one physical server. |
| X86 | / | Generic name for Intel processors released after the original 8086 processor. |
| OpenStack | / | Free, open-source cloud computing platform for IaaS, managing diverse multi-vendor hardware pools of processing, storage, and networking resources. |
| Docker | / | Platform for developers and sysadmins to develop, ship, and run applications using containerization technology. |
| ESXi | / | Virtualization platform for creating and running virtual machines by virtualizing processor, memory, and storage resources. |
| Xen | / | Hypervisor enabling multiple operating systems to execute concurrently on the same hardware. |
| KVM | Kernel-based Virtual Machine | Linux kernel virtualization infrastructure requiring processors with hardware virtualization extensions. |
| LXC | Linux Container | OS-level virtualization for running multiple isolated Linux systems on a single kernel. |
| Hyper-V | / | Microsoft VM system installed on hosts. |
| EC2 | Elastic Compute Cloud | Amazon web service enabling users to rent cloud computers for running applications. |

## Financial Terms

| Term | Full Name | Description |
|------|-----------|-------------|
| CAPEX | Capital Expenditure | Expenditures creating future benefits, incurred when buying fixed assets or adding value to existing assets with useful life beyond the taxable year. |
| OPEX | Operating Expense | Ongoing costs for running a product, business, or system. |
| TCO | Total Cost of Ownership | Financial estimate for determining direct and indirect costs of a product or system, used in cost accounting and decision-making. |

## Cloud Service Models

| Term | Full Name | Description |
|------|-----------|-------------|
| IaaS | Infrastructure as a Service | Enables consumers to use basic computing resources (processing, storage, network) for deploying software without purchasing hardware. Users control OS, storage, and applications but not underlying infrastructure. |
| PaaS | Platform as a Service | Application hosting and development environment providing efficient development tools, middleware services, and DevOps/NoOps capabilities. |
| SaaS | Software as a Service | Cloud providers install and operate applications; users access software via clients without managing infrastructure or platforms, simplifying maintenance and support. |

## Cloud Components & Services

| Term | Full Name | Description |
|------|-----------|-------------|
| ECS | Elastic Cloud Server | Computing server with CPUs, memory, images, and EVS disks, allowing on-demand allocation and elastic scaling. |
| EVS | Elastic Volume Service | Virtual block storage devices using distributed architecture with elastic expansion capabilities. |
| VFW | Virtual Firewall | Network firewall service in virtualized environments providing packet filtering and monitoring like physical firewalls. |
| CRM | Customer Relationship Management | Enterprise strategy for organizing resources effectively and implementing customer-centric processes to improve profitability and satisfaction. |

## Emerging Technologies

| Term | Full Name | Description |
|------|-----------|-------------|
| IoT | Internet of Things | Network of physical devices with embedded electronics, software, sensors, and connectivity enabling data exchange. |
| RFID | Radio Frequency Identification | Wireless technology using radio-frequency electromagnetic fields to identify and track objects without manual intervention. |
| NFV | Network Functions Virtualization | Uses IT virtualization to consolidate network equipment types onto industry standards (servers, switches, storage) across data centers and network nodes. |
| Edge Computing | / | Computing paradigm that pushes applications, data, and services to network edges, enabling analytics and knowledge generation at data sources. |
